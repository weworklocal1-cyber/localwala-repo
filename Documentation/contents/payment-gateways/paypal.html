PayPal Payment Gateway Setup

PayPal allows customers to pay securely using their PayPal balance, cards, or linked bank accounts.
In FoodBite, PayPal integration is fully managed by the backend — you only need to add your PayPal credentials from the Admin Panel.

Step 1: Create or Log In to PayPal Account

  1. Visit the PayPal Developer website
  2. Log in using your PayPal Business account
  3. If you don’t have a business account, upgrade or create one

🔗 PayPal Developer Dashboard: https://developer.paypal.com

Step 2: Access PayPal Developer Dashboard

  1. Open the PayPal Developer Dashboard
  2. Switch between Sandbox and Live mode as needed

Sandbox mode is recommended for testing payments before going live.

Step 3: Create PayPal App

  1. Go to My Apps & Credentials
  2. Select Sandbox or Live
  3. Click Create App
  4. Enter an app name and create the app

After creation, PayPal will generate your credentials.

Step 4: Copy Client ID and Secret

From the app details page, copy:

  • Client ID
  • Secret Key
⚠️ Important:
Keep your Secret Key private and never expose it publicly.

🔗 PayPal API Credentials Guide:
https://developer.paypal.com/docs/api-basics/manage-apps/

Step 5: Add PayPal Credentials in FoodBite Admin Panel

  1. Log in to the FoodBite Admin Panel
  2. Navigate to:
    Business Setup → Payment Settings → PayPal
  3. Paste:
    • PayPal Client ID
    • PayPal Secret Key
  4. Select Sandbox or Live mode
  5. Click Save

Once saved, PayPal payments will be enabled automatically.

Step 6: Test PayPal Payment (Sandbox)

  1. Ensure Sandbox mode is selected
  2. Place a test order from the Customer App or Web App
  3. Use PayPal sandbox buyer account to complete payment

🔗 PayPal Sandbox Testing:
https://docs.paypal.ai/developer/how-to/api/get-started/

Switching to Live Mode

  1. Switch to Live mode in PayPal Developer Dashboard
  2. Copy Live Client ID and Live Secret
  3. Update the credentials in the FoodBite Admin Panel
  4. Save changes

✅ Live PayPal payments are now active.

Notes

  • Webhooks and payment verification are handled automatically by FoodBite
  • No backend or frontend code changes are required
  • Always test payments in sandbox mode before going live

Useful Links

  • 🔗 PayPal Developer Dashboard: https://developer.paypal.com
  • 🔗 Manage Apps & Credentials: https://developer.paypal.com/developer/applications
  • 🔗 PayPal Testing Guide: https://docs.paypal.ai/developer/how-to/api/get-started/
