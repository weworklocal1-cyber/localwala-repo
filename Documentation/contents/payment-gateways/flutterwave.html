Flutterwave Payment Gateway Setup

Flutterwave lets you accept secure online payments using cards, bank transfers, and local payment methods across supported regions.
In FoodBite, Flutterwave integration is fully handled by the backend — you only need to add your Flutterwave credentials from the Admin Panel.

Step 1: Create or Log In to Flutterwave Account

  1. Visit the Flutterwave Dashboard
  2. Log in with your Flutterwave account or sign up for a new business account
  3. Complete any required merchant verification

🔗 Flutterwave Dashboard: https://dashboard.flutterwave.com

Step 2: Switch to Test Mode (Recommended)

Flutterwave provides separate credentials for Test and Live environments.

  1. Log in to the Flutterwave Dashboard
  2. Use Test Mode credentials for testing payments before going live

Step 3: Get Flutterwave API Keys

Your API keys include:

  • Public Key — safe to use in client-side calls
  • Secret Key — used securely by backend systems

To find your keys:

  1. In the Flutterwave Dashboard, go to Settings
  2. Under the Developers section, select API Keys
  3. Your Test and Live keys will be shown (Test keys are prefixed with _TEST)
  4. If needed, click to generate or regenerate keys

🔗 Official guidance on obtaining API keys:
https://developer.flutterwave.com/v3.0/docs/authentication

⚠️ Important: Keep your Secret Key secure — do not expose it publicly.

Step 4: Add Flutterwave Credentials in FoodBite Admin Panel

  1. Log in to the FoodBite Admin Panel
  2. Navigate to:
    Business Setup → Payment Settings → Flutterwave
  3. Enter:
    • Flutterwave Public Key
    • Flutterwave Secret Key
  4. Choose Test Mode or Live Mode
  5. Click Save

Once saved, Flutterwave payments will be enabled automatically.

Step 5: Test Flutterwave Payments

  1. Ensure Test Mode is selected in both Flutterwave and FoodBite
  2. Place a test order from the Customer App or Web App
  3. Complete the payment using Flutterwave test credentials

Test credentials behave like real transactions but do not move actual funds.

Switching to Live Mode

  1. Switch to Live Mode in the Flutterwave Dashboard
  2. Copy the Live Public Key and Live Secret Key
  3. Update them in the FoodBite Admin Panel under Flutterwave
  4. Save changes
✅ Live Flutterwave payments are now enabled.

Notes

  • Webhooks and payment verification are handled automatically by FoodBite
  • No backend or frontend code changes are required
  • Always test payments before enabling live mode

Useful Links

  • 🔗 Flutterwave Dashboard: https://dashboard.flutterwave.com
  • 🔗 Flutterwave API Key Authentication: https://developer.flutterwave.com/v3.0/docs/authentication
