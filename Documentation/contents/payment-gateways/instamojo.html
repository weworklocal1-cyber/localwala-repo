Instamojo Payment Gateway Setup

Instamojo allows you to accept online payments using cards, UPI, net banking, and wallets.
In FoodBite, Instamojo integration is fully handled by the backend — you only need to add your Instamojo credentials from the Admin Panel.

Step 1: Create or Log In to Instamojo Account

  1. Visit the Instamojo Dashboard
  2. Log in to your Instamojo account or sign up for a new one
  3. Complete the merchant account verification

🔗 Instamojo Dashboard: https://www.instamojo.com/dashboard/

Step 2: Enable Test Mode (Optional)

Instamojo allows testing payments before going live.

  1. Log in to the Instamojo Dashboard
  2. Switch to Test Mode if available

Test mode helps verify payments without real transactions.

Step 3: Get API Key and Auth Token

  1. From the Instamojo Dashboard, navigate to:
    Settings → API & Webhooks
  2. Copy the following credentials:
    • API Key
    • Auth Token

🔗 Instamojo API Credentials Guide:
https://www.instamojo.com/payment-gateway-integration/

Step 4: Copy Instamojo Credentials

Make sure you have:

  • API Key
  • Auth Token
⚠️ Important:
Keep your Auth Token secure and never expose it publicly.

Step 5: Add Instamojo Credentials in FoodBite Admin Panel

  1. Log in to the FoodBite Admin Panel
  2. Navigate to:
    Business Setup → Payment Settings → Instamojo
  3. Paste:
    • Instamojo API Key
    • Instamojo Auth Token
  4. Select Test Mode or Live Mode (if applicable)
  5. Click Save

Once saved, Instamojo payments will be enabled automatically.

Step 6: Test Instamojo Payment

  1. Ensure Test Mode is enabled
  2. Place a test order from the Customer App or Web App
  3. Complete the payment using Instamojo test credentials

🔗 Instamojo Testing Guide:
https://test.instamojo.com/integrations/

Switching to Live Mode

  1. Disable Test Mode in Instamojo Dashboard
  2. Use Live API Key and Live Auth Token
  3. Update the credentials in the FoodBite Admin Panel
  4. Save changes

✅ Live Instamojo payments are now active.

Notes

  • Payment callbacks and verification are handled automatically by FoodBite
  • No backend or frontend code changes are required
  • Always test payments before enabling live mode

Useful Links

  • 🔗 Instamojo Dashboard: https://www.instamojo.com/dashboard/
  • 🔗 Instamojo API Docs: https://docs.instamojo.com
  • 🔗 Authentication Guide: https://www.instamojo.com/payment-gateway-integration/
