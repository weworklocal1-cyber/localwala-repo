Change Static Images (Flutter)

Update static images used across FoodBite Flutter applications (Customer, Delivery Partner, Kitchen, Waiter, Restaurant) without modifying code.

📁 Image Assets Directory

All static images are stored inside:

assets/images/

Example structure:

assets/images/
├── logo/
├── banners/
├── icons/
├── placeholders/
└── languages/

🔁 How to Update Existing Images

1️⃣ Prepare Your New Image
  • Use the same image format (.png, .jpg, .webp, etc.)
  • Match the original image dimensions where possible
  • Optimize file size for better performance
2️⃣ Replace the Image File
  1. Locate the existing image inside assets/images/
  2. Replace it with your new image
  3. Keep the file name and extension exactly the same

Example:

assets/images/logo/app_logo.png   ✅
assets/images/logo/app_logo.jpg   ❌ (extension changed)
Important Asset Naming Rule:
  • ❌ Do NOT rename image files
  • ❌ Do NOT change file extensions
  • ❌ Do NOT move images to a different folder

➕ Adding New Images (Optional)

If you are adding new images for custom screens:

  • Place the image inside an appropriate folder under assets/images/
  • Register it in pubspec.yaml if required
  • Reference the image path in code

⚠️ Note: This applies only to new UI development, not existing assets.

🔄 Apply Changes

flutter clean
flutter pub get
flutter run

✅ Verification Checklist

  • ✅ Images updated correctly across all screens
  • ✅ No missing image placeholders
  • ✅ No runtime asset errors in logs
  • ✅ Images display correctly on different screen sizes
  • ✅ Performance and loading speed unaffected
Common Mistakes to Avoid:
  • Renaming image files
  • Changing image extensions
  • Replacing SVG with PNG (or vice versa)
  • Using very large, unoptimized images
  • Forgetting to rebuild the app
