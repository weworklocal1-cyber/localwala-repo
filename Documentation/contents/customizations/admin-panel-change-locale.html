Admin Language Translations (Angular)

Add or update language translations in the FoodBite Admin Panel using ngx-translate.

🌐 Admin Panel Localization Overview

Localization is already configured in the project. You only need to add new language files or update existing translations. No additional dependency installation or configuration is required.

📦 Localization Libraries Used

"@ngx-translate/core": "^15.0.0",
"@ngx-translate/http-loader": "^8.0.0"

📁 Translation File Location

All admin panel translation files are located at:

Admin_panel/src/assets/i18n/

Example structure:

Admin_panel/src/assets/i18n/
├── en.json
├── hi.json
├── ar.json
├── es.json

🗂️ Translation File Structure

Translations use key-value pairs.

Example: en.json
{
  "COMMON": {
    "SAVE": "Save",
    "CANCEL": "Cancel"
  },
  "AUTH": {
    "LOGIN": "Login",
    "LOGOUT": "Logout"
  }
}
Example: es.json
{
  "COMMON": {
    "SAVE": "Guardar",
    "CANCEL": "Cancelar"
  },
  "AUTH": {
    "LOGIN": "Iniciar sesión",
    "LOGOUT": "Cerrar sesión"
  }
}

🔑 Note: Translation keys must match exactly across all language files.

➕ Add a New Language

1️⃣ Create a New JSON File
Admin_panel/src/assets/i18n/fr.json
2️⃣ Copy Base Translations
{
  "COMMON": {
    "SAVE": "Enregistrer",
    "CANCEL": "Annuler"
  }
}

✏️ Update Existing Translations

  • Open the relevant .json file
  • Modify only the values
  • Do not change the keys or structure
  • Save the file

⚠️ Dynamic Translation Rules (Important)

Some translation values contain dynamic placeholders used at runtime.

🔒 Do NOT modify placeholders

Correct example:

"ITEM_COUNT": "Total items: ##$count##"

Translated:

"ITEM_COUNT": "Artículos totales: ##count##"

❌ Incorrect:

"ITEM_COUNT": "Artículos totales: ##cantidad##"

🧩 Using Translations in Templates

HTML Example
{{ 'COMMON.SAVE' | translate }}
TypeScript Example
this.translate.instant("AUTH.LOGIN");

🔄 Apply Changes

After adding or updating translation files:

npm run build

Or during development:

npm start

Hard refresh the browser if changes don’t appear immediately.

✅ Verification Checklist

  • Translation file added under assets/i18n
  • Keys match existing languages
  • Dynamic placeholders remain unchanged
  • UI reflects updated translations
  • No console translation errors
Common Mistakes to Avoid:
  • Renaming existing translation keys
  • Translating dynamic placeholders
  • Breaking JSON formatting
  • Missing commas or braces
  • Forgetting to hard refresh the browser
