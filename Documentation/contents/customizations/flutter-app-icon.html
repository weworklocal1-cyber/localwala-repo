Change App Icon (Flutter)

Update the app icons for Android and iOS in all FoodBite Flutter applications (Customer, Delivery Partner, Kitchen, Waiter, and Restaurant) to match your branding.

This ensures that the app icon on both Android and iOS devices reflects your brand.

📂 Recommended Icon Sizes

For best results, prepare a square PNG icon (preferably 1024x1024 px). The Flutter package will generate all required sizes automatically.

🔧 Steps to Change Android Icon

Step 1: Open Android Module
  1. Open your Flutter project in Android Studio

  1. Navigate to the Android module: android/app/src/main

Step 2: Open Image Asset Tool
  1. Right-click on res folder → New → Image Asset

Path: android/app/src/main/res

Step 3: Configure Icon
  • Icon Type → Launcher Icons (Adaptive and Legacy)
  • Foreground Layer → Select your app icon PNG
  • Background Layer → Choose a background color (optional)
  • Name → ic_launcher (default)

All densities (mdpi, hdpi, xhdpi, xxhdpi, xxxhdpi) are generated automatically.

Step 4: Finish & Verify
  1. Click Next → Finish
  2. Android Studio updates the mipmap-* folders under android/app/src/main/res/
  3. Rebuild the app:
flutter clean
flutter pub get
flutter run

🔧 Steps to Change iOS Icon

Step 1: Generate Icons on AppIcon.co
  1. Open https://www.appicon.co/
  2. Upload your square PNG icon (minimum 1024×1024 px, no transparency)
  3. Select iOS as the platform
  4. Click Generate and download the ZIP file
Step 2: Unzip and Review

Extract the ZIP. It contains multiple icon files for different devices (e.g., Icon-App-20x20@2x.png, Icon-App-60x60@3x.png).

Step 3: Open iOS Project in Xcode

In your Flutter project folder, open ios/Runner.xcworkspace
Always open the .xcworkspace file (not .xcodeproj)

Step 4: Replace Icons in AppIcon Asset
  1. Navigate in Xcode: Runner → Assets.xcassets → AppIcon
  2. Delete existing icons (optional, recommended)
  3. Drag each generated image from AppIcon.co into the correct slots

Ensure all required sizes (iPhone, iPad, App Store) are filled.

Step 5: Verify AppIcon Configuration
  1. Go to Runner → General → App Icons and Launch Images
  2. Ensure AppIcon is selected as the app icon set
  3. Rebuild the app:
flutter clean
flutter pub get
flutter run
Verification Checklist
  • ✅ App icon updated on the iOS home screen
  • ✅ Icon appears in the App Switcher
  • ✅ App Store icon (1024×1024) is correctly set
  • ✅ No missing image warnings in Xcode
  • ✅ Icon displays correctly on different device models and sizes
Important Notes:
  • iOS icons must not be transparent
  • Always include the 1024×1024 App Store icon
  • Do not rename the AppIcon asset in Xcode
  • If icon doesn’t update on a real device:
    • Delete the old app from the device
    • Rebuild and reinstall
