Flutter Setup Guide

Flutter is used to build the Customer App, Restaurant App, Delivery App, Kitchen App, and Waiter App for the FoodBite platform.

⚠️ Important
Flutter setup is required only for local development machines.
Do not attempt to install or run Flutter on a server.
ℹ️ Prerequisites
Flutter requires Git and Android Studio. Make sure both are installed before continuing.

🪟 Flutter Setup on Windows

Step 1: Download Flutter SDK

  1. Visit https://flutter.dev
  2. Navigate to Docs → Get Started → Install → Windows
  3. Choose Android as the app type
  4. Download the stable Flutter SDK (.zip)
  5. Extract the flutter folder to: D:\development\flutter

Step 2: Add Flutter to Environment Variables

  1. Open Control Panel → System → Advanced system settings
  2. Click Environment Variables
  3. Edit Path under User Variables
  4. Add: D:\development\flutter\bin
  5. Save and restart terminal

Step 3: Verify Flutter Installation

flutter

You should see a list of Flutter commands.

Step 4: Install Android Studio

  • Download from https://developer.android.com/studio
  • Install Android Studio and Android Virtual Device (AVD)
  • Keep default JDK and SDK paths

Step 5: Run Flutter Doctor

flutter doctor

Follow the output to resolve missing dependencies.

Step 6: Accept Android Licenses

flutter doctor --android-licenses

Step 7: Setup Emulator or Device

  • Open Android Studio → AVD Manager
  • Create and start an emulator
  • OR connect a physical Android device with USB debugging enabled
Flutter is now ready on Windows 🎉

🍎 Flutter Setup on macOS

Step 1: Download Flutter SDK

  1. Visit flutter.dev
  2. Go to Install → macOS
  3. Download the stable Flutter SDK (.zip)
  4. Extract to ~/development/flutter

Step 2: Add Flutter to PATH

nano ~/.zshrc
export PATH="$PATH:$HOME/development/flutter/bin"
source ~/.zshrc

Step 3: Verify Installation

flutter

Step 4: Install Android Studio

Download and install Android Studio with AVD support.

Step 5: Run Flutter Doctor

flutter doctor

Step 6: Accept Licenses

flutter doctor --android-licenses
Flutter is now ready on macOS 🍎

🐧 Flutter Setup on Linux

Step 1: Download and Extract Flutter


cd ~/development
tar xf ~/Downloads/flutter_linux_x.x.x-stable.tar.xz

Step 2: Add Flutter to PATH


nano ~/.bashrc
export PATH="$PATH:$HOME/development/flutter/bin"
source ~/.bashrc

Step 3: Verify Installation

flutter

Step 4: Install Android Studio

Install Android Studio and required SDK tools.

Step 5: Run Flutter Doctor

flutter doctor

Step 6: Accept Licenses

flutter doctor --android-licenses
Flutter is now ready on Linux 🐧
