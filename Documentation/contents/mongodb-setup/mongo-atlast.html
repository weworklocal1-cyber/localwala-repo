MongoDB Atlas Database Setup

MongoDB Atlas is a fully managed cloud MongoDB service used for hosting FoodBite databases in testing and production environments.

This guide explains how to create a MongoDB Atlas cluster, database, user, and connection string.

Step 1: Login to MongoDB Atlas

  1. Visit 👉 https://www.mongodb.com/atlas
  2. Sign in using Google, GitHub, or Email
  3. You will be redirected to the MongoDB Atlas Dashboard

Step 2: Create a Free Cluster

  1. Click Create
  2. Select M0 Free Tier
  3. Choose:
    • Cloud Provider: AWS / GCP / Azure
    • Region: Choose the nearest region for better performance
  4. Set a cluster name: 
    foodbite-cluster
  5. Click Create Cluster

    ⏳ Cluster provisioning may take 2–5 minutes

Step 3: Create a Database User

  1. Go to Database Access
  2. Click Add New Database User
  3. Select Password Authentication
  4. Enter: 
    Username: foodbite_user
Password: your_secure_password
  5. Set privileges:
    • ✅ Read and write to any database
  6. Click Add User
⚠️ Save username & password (used in MongoDB URI)

Step 4: Allow Network Access (IP Whitelist)

  1. Go to Network Access
  2. Click Add IP Address
  3. Choose:
    • Select Allow Access from Anywhere (for testing)
      • 0.0.0.0/0
  4. Click Confirm
⚠️ For production, restrict to server IP only.

Step 5: Open Cluster & Create Database

  1. Go to Clusters
  2. Click Browse Collections
  3. Click Add My Own Data and fill details: 
    Database Name: foodbite
Collection Name: users
  4. Click Create

✅ Your database is now created!

Step 6: Get MongoDB Connection String

  1. Click Connect
  2. Choose Connect your application
  3. Select:
    • Driver: Node.js
    • Version: Latest
  4. Copy URI: 
    mongodb+srv://foodbite_user:<password>@foodbite-cluster.xxxxx.mongodb.net/foodbite
    Replace:
    • <password> → your database password
    • foodbite → database name

Step 7: Use in Node.js (.env)

Add the MongoDB URI to your .env file:

MONGODB_URI=mongodb+srv://foodbite_user:password@foodbite-cluster.xxxxx.mongodb.net/foodbite

Final Checklist

  • ✔ Cluster created
  • ✔ Database user added
  • ✔ IP whitelisted
  • ✔ Database & collection created
  • ✔ Connection string ready
