Cashfree Payment Gateway Setup

Cashfree allows you to accept online payments using cards, UPI, net banking, wallets, and other local methods. In FoodBite, Cashfree integration is handled fully by the backend — you only need to add your Cashfree credentials from the Admin Panel.

Step 1: Create or Log In to Cashfree Merchant Account

  1. Open your browser
  2. Go to the official Cashfree merchant portal: https://merchant.cashfree.com
  3. Log in or sign up for a merchant account

Complete any verification steps requested (KYC, documentation, etc.).

🔗 Cashfree Merchant Portal: https://merchant.cashfree.com

Step 2: Use Test Mode (Recommended)

Cashfree provides separate credentials for Sandbox (Test) and Live environments. Always use test credentials first to verify payment flows before going live.

Step 3: Generate API Keys (App ID & Secret Key)

  1. From the Cashfree merchant dashboard, go to Developers → API Keys
  2. In the Test environment, API keys are generated automatically
  3. For Live keys, click Generate API Keys and complete 2FA verification
  4. Copy:
    • App ID
    • Secret Key
⚠️ Important: Keep your Secret Key private — never expose it publicly.

🔗 Cashfree API Authentication:
https://www.cashfree.com/docs/docs/api-keys

Step 4: Note the Required API Version

Cashfree requires an API version header in the format YYYY-MM-DD for all API calls.

💡 Example API Version: 2025-01-01

Step 5: Add Cashfree Credentials in FoodBite Admin Panel

  1. Log in to the FoodBite Admin Panel
  2. Navigate to:
    Business Setup → Payment Settings → Cashfree
  3. Enter:
    • Cashfree App ID
    • Cashfree Secret Key
    • API Version
  4. Select Test Mode or Live Mode
  5. Click Save

Once saved, Cashfree payments will be enabled automatically.

Step 6: Test Cashfree Payments

  1. Enable Test Mode in both Cashfree and FoodBite
  2. Place a test order from the customer app or web panel
  3. Complete payment using sandbox/test credentials

Test mode does not process real funds.

Switching to Live Mode

  1. Switch to Live API Keys in the Cashfree dashboard
  2. Copy Live App ID, Live Secret Key, and verify API Version
  3. Update these values in the FoodBite Admin Panel
  4. Save changes
✅ Live Cashfree payments should now work.

Notes

  • Cashfree authentication headers include:
    • x-client-id (App ID)
    • x-client-secret (Secret Key)
    • x-api-version (API Version)
  • Webhooks and payment verification are handled automatically by FoodBite
  • No frontend or backend coding is required
  • Always complete sandbox testing before going live

Useful Links

  • 🔗 Cashfree Merchant Portal: https://merchant.cashfree.com
  • 🔗 Cashfree API Keys Docs: https://www.cashfree.com/docs/docs/api-keys
  • 🔗 Cashfree Payments API Reference: https://www.cashfree.com/docs/api-reference/payments/latest/overview
