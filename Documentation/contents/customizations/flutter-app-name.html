Change App Name (Flutter)

Update the display name of your Flutter applications on Android and iOS using common configuration files.

FoodBite allows you to change the display name of all Flutter applications (Customer, Delivery Partner, Kitchen, Waiter, and Restaurant) using a consistent configuration approach.

📝 Change Flutter App Name

Step 1: Update App Name in Flutter Environment File

This file is used inside the Flutter application to display the app name in UI, headers, and internal references.

File: lib/app/env.dart

static const String appName = 'Your App Name';

This value is commonly used across screens, dialogs, and internal app references.

Step 2: Update App Name in AndroidManifest.xml

This controls the app name shown on Android devices, including the launcher and system UI.

File: android/app/src/main/AndroidManifest.xml

Find:

<application android:label="FoodBite" android:name="${applicationName}" ...>

This change affects how the app name appears on the home screen and recent apps list.

Step 3: Update App Name in iOS Info.plist

This controls the display name on iOS devices and App Store listing.

File: ios/Runner/Info.plist

Find:

<key>CFBundleDisplayName</key>
<string>FoodBite</string>
  
<key>CFBundleName</key>
<string>FoodBite</string>

If CFBundleDisplayName does not exist, add it manually below CFBundleName.

🔄 Verification

After changing the app name, it is important to clean and rebuild your Flutter project to ensure all changes are applied correctly.

Verification Checklist
  • ✅ App name updated inside Flutter UI
  • ✅ Android launcher displays the new app name
  • ✅ iOS home screen shows the updated name
  • ✅ No old app name references remain
Fix Common Issues
flutter clean
flutter pub get
flutter run
Important Notes:
  • Changing the app display name does not affect the Android package name or iOS bundle identifier.
  • The App Store / Play Store listing name can be different from the app name shown on the device.
  • Keep the app name short and clear to avoid truncation on home screens.
