Local Environment

Installation Guide for Node API Setup for local environment

This guide will help you set up and run the FoodBite Node.js API on your local machine for development and testing purposes.

Prerequisites

Before starting, ensure the following are installed:

  • Node.js (v18+ recommended)
  • Yarn or npm
  • MongoDB Compass (for local database testing)
  • Git
  • A code editor (VS Code recommended)

Verify installation:

node -v
yarn -v   # or npm -v
This setup is only for local development and testing. Do NOT run this directly on a production server.

Step 1: Download the App Source Code

Extract your AppSourceCode.zip and navigate to the API folder:

cd AppSourceCode/API

Step 2: Install Dependencies

Install all Node.js dependencies:

yarn install
# or
npm install

Step 3: Setup Environment Variables

1. Copy the example file:

cp .env.example .env
# or
copy .env.example .env

2. Open .env and update:

  • MONGODB_URL – Local MongoDB connection string
    (e.g. mongodb://127.0.0.1:27017/foodbite-local)
  • PORT – Node.js API port (default: 3000)
  • Any other API keys or secret values
Important:
Do NOT commit your .env file to version control. Always use .env.example as a reference.

Step 4: Start MongoDB Locally

Option 1: MongoDB Compass

  • Open MongoDB Compass
  • Create a new connection
  • Use the connection string from .env
  • Ensure the database is running locally

Option 2: Terminal / Command Line

# macOS / Linux
mongod

# Windows (if installed as a service)
net start MongoDB

Option 3: Production Database Setup

If you are planning to deploy the FoodBite API on a production server, use a managed or self-hosted MongoDB instead of local MongoDB.

  • MongoDB Atlas (Cloud – Recommended)
  • Self-hosted MongoDB (AWS, DigitalOcean, VPS)

Follow the MongoDB setup guide here:
MongoDB Setup Documentation

For local development, always use Option 1 or Option 2. Switch to Option 3 only for live server deployment.

Step 5: Firebase Admin & Service Account Setup (Optional)

Important:
  • Place your Firebase service account JSON file at:
    API/src/fcm_keys/serviceAccountKey.json
  • This file is required for Firebase push notifications
  • Commit this file only if your repository is private
  • If you skip Firebase, comment out Firebase initialization in: src/app.js
  • The API will still run normally without Firebase
Documentation Reference:
Step-by-step Firebase service account setup guide:
Firebase Service Account JSON Guide

Step 6: Run the Node.js API

Start the API in development mode:

yarn dev
# or
npm run dev

API will run at:

http://youripaddress:3000

Use Postman to test API endpoints.

Step 7: Test API Endpoints

  1. Import Resource/postman_collection.json into Postman
  2. Update Postman environment variables if required
  3. Test endpoints:
    • Authentication
    • User management
    • Restaurant & Menu management
    • Orders & Payments
    • Delivery tracking
Important Notes:
  • Node.js API is required for local testing of Angular & Flutter apps
  • Do NOT expose your local database to the internet
  • Always store secrets inside .env
  • Verify APIs using Postman before running frontend apps
Recommended:
If you prefer visual guidance, watch the installation video on YouTube. It covers the same steps and helps avoid common setup mistakes.
