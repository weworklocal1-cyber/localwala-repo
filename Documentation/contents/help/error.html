Errors & Troubleshooting

Common errors, causes, and solutions across FoodBite apps, admin panel, and server APIs

This section lists common errors you may encounter while using or customizing FoodBite applications, along with their possible causes and recommended solutions.

📱 Mobile App Errors (Flutter)

App Not Launching After Customization

Possible Causes

  • Incorrect asset paths (icons, images, fonts)
  • Renamed font or image files
  • Missing rebuild after changes

Solution

  • Ensure file names and extensions remain unchanged
  • Verify pubspec.yaml asset paths
  • Run:
flutter clean
flutter pub get
flutter run

Missing Text or Square Boxes (▢▢▢) in UI

Possible Causes

  • Font does not support selected language
  • Missing glyphs for special characters

Solution

  • Use fonts with full multilingual support
  • Verify support for:
    • Arabic (RTL)
    • Hindi (Devanagari)
    • Accents and symbols

App Crashes After Language Change

Possible Causes

  • Missing translation keys
  • Incorrect locale configuration
  • Dynamic values removed from translations

Solution

  • Ensure all locales contain the same keys
  • Do not remove or rename dynamic placeholders
  • Restart the app after locale updates

🧭 Admin Panel Errors (Angular)

Blank Screen After Color or SCSS Update

Possible Causes

  • Invalid SCSS variable values
  • Incorrect hex color format

Solution

  • Verify colors are valid hex values
  • Rebuild the admin panel:
npm run build

Translations Not Updating in Admin Panel

Possible Causes

  • Cached translation files
  • Incorrect JSON structure
  • Missing keys in new language file

Solution

  • Clear browser cache
  • Restart Angular dev server
  • Ensure translation JSON is valid

Images Not Displaying in Admin Panel

Possible Causes

  • Incorrect asset path
  • File name mismatch
  • Image not included in build

Solution

  • Place images inside:
Admin_panel/src/assets/
  • Keep file names and extensions unchanged
  • Restart the Angular server

🌐 Server API Errors

Incorrect Language in Invoice or Summary

Possible Causes

  • Missing translation keys in translate.js
  • Incorrect locale passed from client

Solution

  • Verify locale key exists in:
API/src/utils/translate.js
  • Ensure client sends correct locale code

Dynamic Text Not Replacing Values

Possible Causes

  • Dynamic placeholders removed or renamed
  • Incorrect string interpolation

Solution

  • Never modify dynamic placeholders such as:
##dynamic##, ##dynamic_one##, ##dynamic_two##
  • Keep placeholders intact across all languages

🔄 General Troubleshooting Checklist

  • Clear cache after major changes
  • Rebuild apps after asset updates
  • Test on both light & dark modes
  • Test all enabled languages
  • Verify RTL layout for Arabic
  • Check console logs for errors

🆘 Still Facing Issues?

If the issue persists:

  • Review recent customization changes
  • Compare with default FoodBite configuration
  • Contact support with:
    • App name
    • Platform (Android / iOS / Web / API)
    • Error logs or screenshots
✅ Keeping file names, keys, and placeholders unchanged will prevent 90% of common errors.
