Razorpay Payment Gateway Setup

Razorpay allows you to accept secure online payments using cards, UPI, wallets, and net banking.
In FoodBite, Razorpay integration is fully handled by the backend — you only need to add your Razorpay credentials from the Admin Panel.

Step 1: Create or Log In to Razorpay Account

  1. Visit the Razorpay Dashboard
  2. Log in to your Razorpay account or sign up for a new one
  3. Complete the account activation process

🔗 Razorpay Dashboard: https://dashboard.razorpay.com

Step 2: Switch to Test Mode (Recommended)

  1. Open the Razorpay Dashboard
  2. Enable Test Mode from the top menu

Test mode allows you to verify payments without real transactions.

Step 3: Generate API Keys

  1. From the Razorpay Dashboard, go to:
    Settings → API Keys
  2. Click Generate Key
  3. Razorpay will generate:
    • Key ID
    • Key Secret

🔗 Razorpay API Keys Guide:
https://razorpay.com/docs/api/authentication/

Step 4: Copy Key ID and Key Secret

Copy the following credentials:

  • Key ID
  • Key Secret
⚠️ Important:
Keep your Key Secret secure and never expose it publicly.

Step 5: Add Razorpay Credentials in FoodBite Admin Panel

  1. Log in to the FoodBite Admin Panel
  2. Navigate to:
    Business Setup → Payment Settings → Razorpay
  3. Paste:
    • Razorpay Key ID
    • Razorpay Key Secret
  4. Select Test Mode or Live Mode
  5. Click Save

Once saved, Razorpay payments will be enabled automatically.

Step 6: Test Razorpay Payment

  1. Ensure Test Mode is enabled
  2. Place a test order from the Customer App or Web App
  3. Complete the payment using Razorpay test options

🔗 Razorpay Testing Guide:
https://razorpay.com/docs/payments/payments/test-card-details/

Switching to Live Mode

  1. Disable Test Mode in Razorpay Dashboard
  2. Generate Live Key ID and Live Key Secret
  3. Update the credentials in the FoodBite Admin Panel
  4. Save changes

✅ Live Razorpay payments are now active.

Notes

  • Payment verification and callbacks are handled automatically by FoodBite
  • No backend or frontend code changes are required
  • Always test payments before enabling live mode

Useful Links

  • 🔗 Razorpay Dashboard: https://dashboard.razorpay.com
  • 🔗 Razorpay API Documentation: https://razorpay.com/docs/
  • 🔗 Razorpay Test Payments: https://razorpay.com/docs/payments/payments/test-card-details/
