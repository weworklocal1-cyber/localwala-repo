Admin Panel – Production Deployment

This guide explains how to build the Angular Admin Panel for production and upload it to a live server using Nginx.

Step 1: Prerequisites

Before deploying, ensure:

  • Admin Panel is working locally
  • Node.js API is deployed and accessible
  • Server has Nginx installed
  • Domain or subdomain is ready (example: admin.yourdomain.com)

Step 2: Configure Production API URL

Open the production environment file:

src/environments/environment.development.ts and environment.ts

1. Open the environment file:

src/environments/environment.development.ts

2. Update the apiUrl:

export const environment = {
  production: false,
  appName: 'FoodBite',
  apiUrl: 'https://node-api-test.site/', // your live API is deployed and accessible
  defaultCountryCode: '+61',
  version: '1.0.0'
};

For production builds:

src/environments/environment.ts
export const environment = {
  production: false,
  appName: 'FoodBite',
  apiUrl: 'https://node-api-test.site/',
  defaultCountryCode: '+61',
  version: '1.0.0'
};

Step 3: Build Angular Admin Panel

From the Admin_Panel directory:

npm run build

After build completion, Angular will generate:

dist/
 └── foodbite-web-angular/
     ├── index.html
     ├── assets/
     └── *.js
⚠️ Folder name may vary based on angular.json.

Step 4: Upload Production Build to Server

ℹ️ Deployment Note:
For demo purposes, we will deploy the Angular Admin Panel to a cPanel subdomain (test.elitecanyon.com).
You can host the Admin Panel on any server that supports static HTML files, such as DigitalOcean, AWS, shared hosting, or VPS servers.
Angular generates a static production build, which works on all standard web servers including Nginx, Apache, and cPanel-based hosting.

1. Login to cPanel

  • Open your cPanel login URL
  • Login using your hosting credentials

2. Open File Manager

  • Navigate to File Manager
  • Open the root directory: 
    /public_html/

3. Upload dist ZIP File

Instead of uploading individual files, it is recommended to upload the compressed build.

  • On your local machine, compress the Angular build folder: 
    dist/foodbite-web-angular → foodbite-web-angular.zip
  • Upload the ZIP file to your server using File Manager: 
    /public_html/ or /public_html/subdomain/
  • After upload, right-click → Extract the ZIP file

This will create:

/public_html/foodbite-web-angular/ or /public_html/subdomain/foodbite-web-angular

4. Move Build Files to Domain Folder

Move all extracted files to your desired domain folder.

Example: Demo Subdomain

/public_html/test.elitecanyon.com/

Final structure should look like:

/public_html/test.elitecanyon.com/
 ├── index.html
 ├── assets/
 └── *.js

5. Verify Deployment

Open your browser and access your domain:

https://test.elitecanyon.com

⚠️ Important Notes & Common Issues

Before contacting the support team, please review the common issues below. Most deployment problems are caused by incorrect file placement or configuration.

❌ Admin Panel Shows Blank Page

Possible Causes:

  • index.html is not placed in the domain root folder
  • Build files are inside an extra subfolder
  • Browser cache issue

Fix:

  • Ensure files are directly inside: 
    /public_html/test.elitecanyon.com/
  • Clear browser cache and reload

✅ Final Checklist Before Going Live

  • Admin panel loads without errors
  • HTTPS is enabled
  • API endpoints respond correctly
  • Login and dashboard work as expected

📞 Support & Assistance

  • If you are still facing issues after following this guide:
  • Please recheck all steps carefully
  • Make sure you followed the correct deployment path
  • Attach screenshots, error messages, and domain URL when contacting support
Tip: The Admin Panel deployment was successful if the application loads correctly, login works, and API requests return valid responses.
Always verify functionality before sharing the live URL with users.
Recommended: If you prefer visual guidance, we strongly recommend watching the installation video on YouTube.
It covers the same steps shown in this guide and can help avoid common setup mistakes.
