Angular Setup Guide

Angular is used for running and building the Admin Panel of the application. Before installing Angular, you must install Node.js, as Angular CLI depends on npm.

⚠️ Caution:
Angular Admin Panel must be built locally.
Do not attempt to build or run it on a server.
Important:
Make sure Node.js is already installed on your system.
If not, complete the Node.js Setup Guide first.

Prerequisites

  • ✅ Node.js (LTS version recommended)
  • ✅ npm (comes bundled with Node.js)
  • ✅ Internet connection
  • ✅ Basic command-line knowledge (Terminal / Command Prompt)

Verify Node.js installation:

node -v
npm -v

Install Angular CLI

Angular CLI is the official tool used to create, build, and manage Angular projects.

Windows

Open Command Prompt or PowerShell as Administrator:

npm install -g @angular/cli

macOS & Linux

Open Terminal and run:

npm install -g @angular/cli

If you face permission issues:

sudo npm install -g @angular/cli

Verify Angular Installation

After installation, verify Angular CLI:

ng version

You should see:

  • Angular CLI version
  • Node.js version
  • npm version

This confirms Angular CLI is installed correctly.

💡 Recommended:
Watch the YouTube video for visual guidance and to avoid common installation issues.
