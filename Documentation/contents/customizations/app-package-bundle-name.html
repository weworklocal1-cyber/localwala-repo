App Package / Bundle Name (Flutter)

Configure the Android App Package Name and iOS Bundle Identifier to uniquely identify each FoodBite application on app stores and publish them under your own brand without conflicts.

FoodBite allows you to fully customize each mobile application’s App Package Name (Android) and Bundle Identifier (iOS) to match your own brand and company identity. This ensures your apps are uniquely identified on the Google Play Store and Apple App Store, preventing conflicts and enabling proper publishing under your developer account.

Each FoodBite app uses a separate identifier, allowing you to manage Customer, Delivery Partner, Restaurant, Kitchen, and Waiter apps independently while maintaining consistent naming conventions across platforms.

🚀 Change Package / Bundle Identifier

🔹 For Both Android & iOS

Replace com.your.new.package with your new unique identifier:

dart run change_app_package_name:main com.your.new.package

Example: For the Customer App

dart run change_app_package_name:main com.foodbite.customer

Repeat for Delivery, Waiter, Kitchen, and Restaurant apps with their respective package names.

🔹 For Android Only
dart run change_app_package_name:main com.foodbite.customer --android
🔹 For iOS Only
dart run change_app_package_name:main com.foodbite.customer --ios

🗂 What This Tool Updates

  • AndroidManifest.xml – Updates package name for debug, profile, and release builds
  • build.gradle – Updates the applicationId for Android
  • MainActivity files & directory structure – Renames Java/Kotlin package folders and updates references
  • iOS Bundle Identifier – Updates the bundle identifier inside the Xcode project

🔄 Verification

After changing the App Package Name or Bundle Identifier, clean and rebuild your Flutter project.

Verification Checklist
  • ✅ Android applicationId and namespace are updated
  • ✅ iOS Bundle Identifier is updated in Xcode
  • ✅ Firebase app configurations match the updated identifiers
  • ✅ No old package references remain in the project

⚠️ Common Errors & Fixes

❌ App Crashes on Launch

Cause: Cached build data or mismatched package references

Fix:

flutter clean
flutter pub get
flutter run
Important Notes:
  • Changing the Android Package Name or iOS Bundle Identifier affects how the app is identified on the Play Store and App Store.
  • Once an app is published, the package name or bundle identifier cannot be changed.
  • Package names and bundle identifiers must be globally unique.
  • Always update Firebase, payment gateways, and third-party services to match the new identifiers.
  • Perform a clean rebuild after making changes to avoid cached configuration issues.
