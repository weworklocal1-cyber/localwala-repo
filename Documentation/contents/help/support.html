🕒 Support Availability

    • Email: 24–48 business hours

🛠️ Before Contacting Support

Please prepare the following to help us assist you faster:

  • App name (Customer / Delivery / Admin / Kitchen / Waiter)
  • Platform (Flutter, Angular Admin, API)
  • Issue description
  • Screenshots or error logs (if applicable)
  • Version or commit reference (if modified)

⚠️ Important Notes

  • Support is provided only for original FoodBite customers
  • Custom code changes outside documentation may not be covered
  • Third-party service issues (Firebase, Stripe, Google Maps, etc.) are handled as guidance only
