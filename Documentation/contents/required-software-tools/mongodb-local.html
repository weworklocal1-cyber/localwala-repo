MongoDB Local Setup

MongoDB Community Server is required to run MongoDB locally, and MongoDB Compass is used to visualize, query, and manage your databases during development.

This guide explains how to install MongoDB Community + MongoDB Compass on Windows, macOS, and Linux for local testing with FoodBite.

MongoDB Community Server and MongoDB Compass are required only for local development and testing.
Do not use this setup for production servers.

For Production MongoDB Setup, refer to the Production Setup section.

🪟 Windows Setup

MongoDB Community Server & Compass on Windows

This setup is only for local testing, not for production deployment. MongoDB Compass is a GUI tool to visualize, query, and manage MongoDB databases locally.

Step 1: Install MongoDB Community Server

  1. Visit: https://www.mongodb.com/try/download/community
  2. Select:
    • Platform: Windows
    • Package: MSI
  3. Download and run the installer
  4. Choose Complete installation
  5. Enable Install MongoDB as a Service
  6. Select Run service as Network Service user
  7. Finish installation

MongoDB will run on port 27017.

Step 2: Download MongoDB Compass

  1. Visit: https://www.mongodb.com/try/download/compass
  2. Select Windows
  3. Download the stable version

Step 3: Install MongoDB Compass

  1. Run the downloaded installer
  2. Accept license agreement
  3. Click Next → Install → Finish

Step 4: Launch & Connect

mongodb://localhost:27017

Step 5: Verify

  • Databases should appear in MongoDB Compass
  • You can create, query, and manage collections

🍎 macOS Setup

Step 1: Install MongoDB Community Server (Homebrew)

/bin/bash -c "$(curl -fsSL https://raw.githubusercontent.com/Homebrew/install/HEAD/install.sh)"
brew tap mongodb/brew
brew install mongodb-community@7.0
brew services start mongodb-community@7.0

MongoDB runs on port 27017.

🐧 Linux Setup

Install MongoDB Community Server

curl -fsSL https://pgp.mongodb.com/server-7.0.asc | sudo gpg -o /usr/share/keyrings/mongodb-server-7.0.gpg --dearmor
echo "deb [ signed-by=/usr/share/keyrings/mongodb-server-7.0.gpg ] https://repo.mongodb.org/apt/ubuntu jammy/mongodb-org/7.0 multiverse" | sudo tee /etc/apt/sources.list.d/mongodb-org-7.0.list
sudo apt update
sudo apt install -y mongodb-org
sudo systemctl start mongod
sudo systemctl enable mongod

Install MongoDB Compass

sudo dpkg -i mongodb-compass_x.x.x_amd64.deb
sudo apt-get install -f

Connect

mongodb://localhost:27017
