Customer App Setup (Flutter)

This guide will help you set up and run the FoodBite Customer Flutter application on web, emulator, or physical devices.

✅ Prerequisites

Before starting, make sure you have:

  • Flutter SDK installed
  • Android Studio / Xcode (for emulator or simulator)
  • Chrome browser (for web testing)
  • A configured FoodBite Node.js API (local or live)

🧩 Step-by-Step Setup

1️⃣ Open Project in Code Editor

Extract the FoodBite Customer Flutter project and open it in your preferred code editor:

  • VS Code
  • Android Studio
  • IntelliJ IDEA

2️⃣ Install Flutter Dependencies

Run the following command in the project root directory:

flutter pub get

This will download and install all required Flutter packages.

3️⃣ Change App Package / Bundle Name

You must update the application package name for both Android and iOS platforms.

👉 Follow the detailed guide here:

  • Change App Package & Bundle Name

4️⃣ Change Application Name

Update the display name of the app for Android, iOS, and Web.

👉 Follow the guide here:

  • Change Flutter App Name

5️⃣ Setup Firebase (Required)

FoodBite uses Firebase for services such as push notifications and authentication.

⚠️ Important (Fresh Firebase Setup)
If you are reconfiguring Firebase or using a different Firebase project, delete any existing Firebase configuration files first to avoid conflicts.

Delete the following files from your Customer Source Code:

  • firebase.json
  • lib/firebase_options.dart
  • android/app/google-services.json
  • ios/Runner/GoogleService-Info.plist

Steps included in the guide:

  • Install Firebase CLI
  • Configure Firebase project
  • Connect Flutter app using FlutterFire

👉 Complete guide available here:

  • Firebase Setup using FlutterFire CLI

Run FlutterFire configuration:

flutterfire configure

Follow the CLI prompts to:

  • Select your Firebase project
  • Choose Android & iOS platforms
  • Automatically regenerate Firebase configuration files

6️⃣ Setup Google Maps API Keys

FoodBite requires Google Maps for location services, directions, and distance calculations.

👉 Follow this guide to configure keys securely for Android, iOS, and Web:

  • Google Maps API Keys Setup

7️⃣ Configure API (Local or Live)

Connect your Flutter app with the FoodBite Node.js API.

Supported environments:

  • Local API (for development)
  • Live / Production API (AWS, DigitalOcean, etc.)

👉 Refer to the API setup documentation:

  • Node.js API Setup

8️⃣ Additional Customizations

For UI changes, feature toggles, branding, and advanced behavior modifications:

👉 Explore all customization options here:

  • Customization Guides

▶️ Run the Application

9️⃣ Run on Chrome (Web)

flutter run -d chrome

🔟 Run on Emulator or Simulator

Make sure an emulator or simulator is running, then execute:

flutter run

✅ You're All Set!

Your FoodBite Customer App should now be running successfully 🎉

If you face any issues, please check the following:

  • Recheck Firebase & Google Maps configuration
  • Ensure the API base URL is correct (local or live)
  • Run the following command to validate your Flutter environment: 
    flutter doctor
⚠️ Important Web & Device Testing Notice:
Google Maps services will not work correctly on the Chrome browser.
Additionally, many native Flutter packages such as:
  • Payments & payment gateways
  • Device-specific services
  • Background services
  • Certain Firebase native features
are not supported on Flutter Web.
👉 For full functionality testing, you must use:
  • Android Emulator
  • iOS Simulator
  • Real Android or iOS device
Web (flutter run -d chrome) should be used for UI testing only, not for production-level feature validation.
Recommended: If you prefer visual guidance, we strongly recommend watching the installation video on YouTube.
It covers the same steps shown in this guide and can help avoid common setup mistakes.
