Angular Admin Panel – Local API Setup

This guide explains how to set up the FoodBite Angular Admin Panel and connect it with the Node.js API running locally for development and testing.

Step 1: Prerequisites

Ensure the following tools are installed on your system:

  • Node.js (v18+ recommended)
  • npm or yarn
  • Angular CLI
  • MongoDB (local or Atlas)
  • Google Maps Keys

Verify installations:

node -v
npm -v
ng version

Step 2: Extract CodeCanyon Source Code

After purchasing FoodBite from CodeCanyon, you will receive a ZIP file:

AppSourceCode.zip

Extract the ZIP file:

AppSourceCode/
├── Admin_panel
├── API
├── Customer_app
├── Deliveryman_app
├── Kitchen_app
├── Restaurant_app
├── Resource
├── Waiter_app
└── documentation.html

Navigate to the Admin_Panel directory:

cd AppSourceCode/Admin_Panel
⚠️ Do NOT rename folders, as internal paths are already configured.

Step 3: Install Admin Panel Dependencies

Inside the Admin_Panel folder, run:

npm install

This will install all Angular dependencies required for the admin panel.

Step 4: Run Node.js API Locally

Before starting the Admin Panel, you must run the FoodBite Node.js API locally.

Please follow the dedicated backend setup guide:

👉 Node API Local Setup Guide

This document covers:

  • Backend dependency installation
  • Environment variable configuration
  • MongoDB connection
  • Running API in development mode
  • Ensure the API is running successfully before continuing

Default local API URL:

http://localhost:3000

Step 5: Configure API Base URL in Angular

  1. Open the environment file: 
    src/environments/environment.development.ts
  2. Update the apiUrl: 
    export const environment = {
  production: false,
  appName: 'FoodBite',
  apiUrl: 'http://localhost:3000/', // or your current ip address
  defaultCountryCode: '+61',
  version: '1.0.0'
};
  3. For production builds: 
    src/environments/environment.ts
    export const environment = {
  production: false,
  appName: 'FoodBite',
  apiUrl: 'https://yourapidomain.com/',
  defaultCountryCode: '+61',
  version: '1.0.0'
};

Step 6: Start Angular Admin Panel

Return to the Admin Panel directory and start the server:

npm start

Open your browser:

http://localhost:4200

Step 7: Verify API Integration

After starting both the Node.js API and Angular Admin Panel, verify the integration using the following checklist:

  • ✅ Admin login works correctly
  • ✅ Dashboard data loads without errors
  • ✅ Restaurants, orders, and users are displayed
  • ✅ No CORS or 401 Unauthorized errors

Check API Requests

Open Browser DevTools:

  • Right-click → Inspect
  • Go to Network tab
  • Monitor API requests and responses

All API calls should return valid responses (200 / 201 status).

Step 8: Common Issues & Fixes

❌ API Not Connecting

Possible Fixes:

  • Ensure the Node.js API server is running
  • Verify the API URL in: 
    src/environments/environment.ts or environment.development.ts
Recommended: If you prefer visual guidance, we strongly recommend watching the installation video on YouTube.
It covers the same steps shown in this guide and can help avoid common setup mistakes.
