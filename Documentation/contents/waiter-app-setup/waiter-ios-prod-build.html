iOS Prod Build (Xcode)

This guide explains how to generate a production-ready iOS build for the FoodBite Waiter App and upload it to App Store Connect.

✅ Prerequisites

Before generating the iOS production build, ensure that:

  • All Waiter App setup steps are completed
  • Firebase is properly configured for iOS
  • Google Maps API key is added for iOS
  • API base URL points to production server
  • iOS bundle identifier is finalized
  • You are using macOS with Xcode installed
  • You have an Apple Developer Account

1️⃣ Update App Version & Build Number

Open pubspec.yaml and update:

version: 1.0.0+1
  • 1.0.0 → App version (App Store)
  • +1 → Build number (must be incremented for every upload)

2️⃣ Configure iOS Bundle Identifier

Open Xcode:

open ios/Runner.xcworkspace
  • Select Runner → General
  • Update Bundle Identifier (example):
com.yourcompany.foodbite.waiter

3️⃣ Configure App Signing & Capabilities

  1. Open your project: 
    open ios/Runner.xcworkspace
  2. Select the Runner target → Signing & Capabilities
  3. Enable Automatically manage signing
  4. Select your Apple Developer Team
  5. Ensure the following capabilities are enabled if required:
    • Push Notifications
    • Background Modes
    • Sign in with Apple (if used)

4️⃣ Archive & Upload via Xcode

  1. Open Xcode: 
    open ios/Runner.xcworkspace
  2. Go to the menu: Product → Archive
  3. Wait for the archive process to complete. The Organizer window will open automatically.
  4. Click Distribute App
  5. Choose App Store Connect → Upload
  6. Follow the on-screen Xcode steps to complete the upload to App Store Connect

5️⃣ Submit App via App Store Connect

  1. Login to App Store Connect
  2. Select your app
  3. Navigate to TestFlight or App Store
  4. Add the uploaded build
  5. Complete the required details:
    • App information
    • Screenshots
    • Privacy policy
  6. Submit the app for review
Apple Production Build Notice:
iOS builds must be generated on macOS using Xcode. Production certificates and provisioning profiles should never be created on production servers.
Real Device Requirement:
Flutter Web and the iOS Simulator do not fully support native features, including:
  • Payments
  • Push notifications
  • Background services
Always test production builds on a real iPhone device before submitting to the App Store.
Recommended Practice:
Generate iOS production builds locally and upload only the final archive using Xcode Organizer.
