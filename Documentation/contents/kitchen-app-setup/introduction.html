Introduction

The Kitchen App is used by kitchen staff to manage incoming orders, view order details, track preparation status, update order progress, and ensure timely food preparation within the FoodBite platform.

This section will guide you through setting up the Kitchen App for both local development and production environments, ensuring correct configuration and smooth day-to-day operations.

You will learn how to:

  • Set up the Flutter development environment
  • Configure Firebase services for the Kitchen App
  • Install and manage app dependencies
  • Configure environment variables and API endpoints
  • Run the Kitchen App locally on Android and iOS devices
  • Generate production-ready builds for store or device deployment

Before proceeding, make sure the following tools are installed and properly configured on your local machine:

  • Flutter SDK
  • Firebase project
  • Firebase CLI
  • FlutterFire CLI

Follow the setup guides before continuing:

👉 Flutter Setup Guide

👉 Firebase CLI & FlutterFire Setup

Important Production Build Notice:
You must complete all setup steps locally before attempting to run or build the Kitchen App.
The build process and Firebase configuration rely on development tools and credentials that should not be generated, modified, or installed directly on a production environment.
After generating production builds locally, upload only the final app bundles (APK/AAB for Android, IPA for iOS) to the respective app stores.
