Change App Fonts (Flutter)

Update typography across all FoodBite Flutter applications (Customer, Delivery Partner, Kitchen, Waiter, Restaurant) using predefined font files.

🔤 Font Directory Structure

All font files are stored at:

assets/fonts/

Current font files:

assets/fonts/
├── bold.ttf
├── medium.ttf
├── regular.ttf
└── semibold.ttf

These filenames are used throughout the app, including theme configuration and text styles.

🔁 How to Change Fonts (Recommended Way)

1️⃣ Prepare Your New Font Files
  • Download or purchase your desired font family
  • Ensure it supports all required languages (especially Arabic, Hindi, etc.)
  • Export font weights matching:
    • Regular
    • Medium
    • SemiBold
    • Bold
2️⃣ Replace Existing Font Files

Replace the font files one by one and keep filenames exactly the same:

Existing File Replace With
regular.ttf New font regular weight
medium.ttf New font medium weight
semibold.ttf New font semibold weight
bold.ttf New font bold weight

🎨 Where Fonts Are Applied

Fonts are already configured globally inside the app theme:

fontFamily: 'regular'
🔤 Font Weights Usage
  • regular → Normal body text
  • medium → Labels and subtitles
  • semibold → Section headers
  • bold → Titles and emphasized text

No additional code changes are required after replacing the font files.

🌍 Multilingual Font Support

  • Ensure all supported languages render correctly
  • Arabic fonts support RTL (Right-to-Left) layout
  • Hindi fonts support Devanagari characters
  • Accents, symbols, and special characters render properly

Using incomplete fonts may result in missing characters or fallback system fonts.

✅ Verification Checklist

  • ✅ New font visible across all screens
  • ✅ Font weights apply correctly (regular, medium, bold)
  • ✅ No fallback system fonts appear
  • ✅ Text renders correctly in all languages
  • ✅ No layout overflow or clipping issues

Fix Common issues:

flutter clean
flutter pub get
flutter run
🚨 Common Mistakes to Avoid:
  • Renaming font files
  • Using fonts without required language glyphs
  • Mixing different font families for different weights
  • Forgetting to rebuild the app after replacing font files
Important Naming Rule (Must Follow):
  • ❌ Do NOT rename font files
  • ❌ Do NOT change font family names in code
  • ❌ Do NOT update font references in theme.dart
  • The app relies on these fixed filenames across all modules
  • Renaming will cause missing font errors or fallback fonts
