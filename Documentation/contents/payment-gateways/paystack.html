Paystack Payment Gateway Setup

Paystack allows you to accept secure online payments using cards, bank transfers, and mobile money.
In FoodBite, Paystack integration is fully handled by the backend — you only need to enter your Paystack credentials from the Admin Panel.

Step 1: Create or Log In to Paystack Account

  1. Go to the Paystack Dashboard
  2. Log in with your Paystack account or sign up for a new business account

🔗 Paystack Dashboard: https://dashboard.paystack.com

Paystack supports both test and live environments with separate API keys for each.

Step 2: Find Your Paystack API Keys

  1. In your Paystack Dashboard, navigate to:
    Settings → API Keys & Webhooks
  2. Here you will see:
    • Public Key (starts with pk_test_ or pk_live_)
    • Secret Key (starts with sk_test_ or sk_live_)

🔗 Paystack Authentication Docs: https://paystack.com/docs/api/authentication/

⚠️ Important: Keep your Secret Key secure and do not share it publicly.

Step 3: Copy Public and Secret Keys

  • Public Key
  • Secret Key

You should use Test keys for testing, and switch to Live keys only when ready for production.

Step 4: Add Paystack Credentials in FoodBite Admin Panel

  1. Log in to your FoodBite Admin Panel
  2. Navigate to:
    Business Setup → Payment Settings → Paystack
  3. Paste:
    • Paystack Public Key
    • Paystack Secret Key
  4. Select Test Mode or Live Mode
  5. Save your changes

Once saved, Paystack payments will be enabled automatically.

Step 5: Test Paystack Payments

  • Make sure Test Mode is enabled
  • Place a test order from the Customer App or Web App
  • Complete payment using Paystack test credentials

Test keys behave like live payments but with no real money movement.

Switching to Live Mode

  1. Switch to Live API Keys in your Paystack Dashboard
  2. Copy Live Public Key and Live Secret Key
  3. Update those in FoodBite Admin Panel under Paystack settings
  4. Save changes
✅ Live Paystack payments will now be accepted.

Notes

  • Webhooks and payment verification are handled automatically by FoodBite
  • No backend code changes are required
  • Always test payments before enabling live mode

Useful Links

  • 🔗 Paystack Dashboard: https://dashboard.paystack.com
  • 🔗 Paystack Authentication Docs: https://paystack.com/docs/api/authentication/
