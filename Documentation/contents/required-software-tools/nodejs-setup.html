Node.js Setup Guide

Node.js is required to run the FoodBite backend and execute Angular npm commands.
This guide will walk you through installing Node.js and Yarn (or NPM) on your system.

Node.js is required for the Angular Admin Panel backend and local API testing.
Use this setup only on your local machine, not on a production server.

⚠️ For production server setup, please refer to the Production Setup documentation.

🪟 Windows Setup

Installing Node.js on Windows

Installing Node.js on Windows is a simple and reliable process when the correct steps are followed. A proper installation ensures Node.js and NPM work smoothly.

  • Official Node.js installer
  • Node Version Manager (NVM)
  • Windows Subsystem for Linux (WSL)
  • Windows package managers

Prerequisites

  • Windows 7 or later
  • Administrator access
  • Stable internet connection
  • Visual Studio Code or preferred editor
  • Minimum 2 GB RAM
Recommended: Use the official LTS installer from Node.js

🐧 Linux Setup

Update System

Upgrade

Install npm

sudo apt install npm
