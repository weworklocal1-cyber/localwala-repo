Change App Color (Flutter)

Customize primary, secondary, and theme colors for FoodBite Flutter applications (Customer, Delivery Partner, Kitchen, Waiter, and Restaurant) using a centralized theme configuration.

This ensures a consistent brand appearance in both Light Mode and Dark Mode.

🎨 Theme Configuration File

All color-related changes are managed from a single file: 

lib/app/presentation/styles/theme.dart

This file controls:

  • Primary and secondary colors
  • Background and page background colors
  • Canvas color
  • AppBar colors
  • Button colors
  • Light and Dark mode variants
  • Icon, text, and shadow colors

Updating colors here will automatically apply across the entire app.

🌓 Light Theme Color Changes

In theme.dart, locate the light theme colors inside ThemeProvider and appThemeData[AppTheme.light].

Key Properties
  • primaryColor
  • secondaryColor
  • backgroundColor
  • pageBackgroundColor
  • canvasColor
  • shadowColorLight
  • lightDisabledColor
  • ratingBgColorLight, ratingTextColorLight, ratingStarIconColorLight
  • offerTagTextColorLight
Example Update
static const Color primaryColor = Color(0xFFFF5722);
static const Color secondaryColor = Color(0xFFFFCCBC);
static const Color backgroundColor = Color(0xFFF5F5F5);
static const Color pageBackgroundColor = Color(0xFFFFFFFF);
static Color lightDisabledColor = Colors.grey.shade200;

🌙 Dark Theme Color Changes

Similarly, locate the dark theme colors inside ThemeProvider and appThemeData[AppTheme.dark].

Key Properties
  • darkPrimaryColor
  • darkSecondaryColor
  • darkBackgroundColor
  • darkPageBackgroundColor
  • darkCanvasColor
  • darkDisabledColor
Example Update
static const Color darkPrimaryColor = Color(0xFFFF5722);
static const Color darkSecondaryColor = Color(0xFF222222);
static const Color darkBackgroundColor = Color(0xFF2C2C2C);
static const Color darkPageBackgroundColor = Color(0xFF1F1F1F);
static const Color darkCanvasColor = Color(0xFF121212);

Ensure sufficient contrast for readability in dark mode.

🔄 Apply Changes

After updating the colors, clean and rebuild the app:

flutter clean
flutter pub get
flutter run

Test both light and dark modes on multiple devices to ensure color consistency.

Verification Checklist

  • ✅ Light mode colors are updated correctly across all screens
  • ✅ Dark mode colors are updated correctly across all screens
  • ✅ AppBar, buttons, icons, and texts reflect the new colors
  • ✅ No visual contrast or readability issues
Important Notes:
  • Do not modify colors directly inside widgets unless necessary. Update ThemeProvider for consistency.
  • Always test both light and dark themes after changing colors.
  • Keep primary and secondary colors distinct to maintain clear UI hierarchy.
  • Use sufficient contrast for accessibility in both themes.
