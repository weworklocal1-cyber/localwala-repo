Google Maps API Key Setup

FoodBite uses the Google Maps Platform to provide essential location-based features across Web and Mobile applications.

  • 🗺️ Maps display
  • 🔍 Places Autocomplete
  • 🧭 Directions & Routes
  • 📍 Markers & Pins
  • 📏 Distance Calculation

This guide explains how to create and secure Google Maps API keys for:

  • Angular Web
  • Flutter Android
  • Flutter iOS

Required Google Maps APIs

Enable the following APIs for all platforms:

  • Maps JavaScript API (Web)
  • Maps SDK for Android
  • Maps SDK for iOS
  • Places API
  • Directions API
  • Distance Matrix API
  • Geocoding API (recommended)

Create Google Cloud Project

  1. Open Google Cloud Console
  2. Click Select Project → New Project
  3. Enter project name (example):
FoodBite Maps

Click Create and wait for project setup to complete.

Create API Key

  1. Go to APIs & Services → Credentials
  2. Click Create Credentials → API Key
  3. Copy the generated API key
  4. Click Edit Key to apply restrictions

Secure the API Key (Very Important)

Restrict APIs

Under API Restrictions, allow only:

  • Maps JavaScript API
  • Maps SDK for Android
  • Maps SDK for iOS
  • Places API
  • Directions API
  • Distance Matrix API
💡 Recommended:
Watch the YouTube video for visual guidance to avoid API restriction mistakes.
▶

Angular Web (Maps JavaScript API)

Restrict Key for Web

  1. Application Restriction → HTTP Referrers
  2. Add allowed domains:
https://yourdomain.com/
https://www.yourdomain.com/
http://localhost:4200/

Flutter Android Setup

Restrict Key for Android

  1. Application Restriction → Android Apps
  2. Add Package Name
  3. Add SHA-1 Fingerprint

Get SHA-1 Fingerprint

cd android
./gradlew signingReport

Copy the generated SHA-1 value.

Flutter iOS Setup

Restrict Key for iOS

  1. Application Restriction → iOS Apps
  2. Add Bundle Identifier
com.foodbite.customer

Security Best Practices (Mandatory)

  • ✅ Use separate API keys for Web, Android, and iOS
  • ✅ Enable billing (required by Google)
  • ✅ Always restrict APIs and platforms
  • ❌ Never expose unrestricted keys
  • ❌ Never commit API keys to public repositories
