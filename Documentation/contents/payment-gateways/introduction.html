Payment Gateway Setup

FoodBite provides built-in support for multiple popular payment gateways.
To enable online payments, you only need to enter the required gateway credentials in the Admin Panel — all payment processing, validation, and order handling are managed automatically by the FoodBite backend.

No additional coding or manual integration is required.

Supported Payment Gateways

FoodBite currently supports the following payment gateways:

  • Stripe
  • PayPal
  • Razorpay
  • Instamojo
  • Paystack
  • Flutterwave
  • Cashfree
  • Xendit

How It Works

The payment setup process in FoodBite is simple:

  1. Choose a payment gateway from the Admin Panel
  2. Enter the required API credentials (Test / Live)
  3. Enable the gateway
  4. Start accepting payments

Once credentials are saved:

  • Payment requests are securely handled by the backend
  • Order verification and status updates are automatic
  • Webhooks and callbacks are processed internally
  • Mobile apps and web panels work seamlessly without extra setup

What You Need to Provide

From the Admin Panel → Payment Gateway Settings, you only need to add:

  • API Key / Secret Key (as required by the gateway)
  • Merchant ID (if applicable)
  • Sandbox or Live mode selection

That’s it — no backend changes required.

Platform Compatibility

Payment gateways work across all FoodBite applications:

  • 📱 Flutter Customer App (Android & iOS)
  • 🏪 Restaurant App
  • 🚚 Delivery App
  • 🖥️ Web Admin & Vendor Panels
  • ⚙️ Node.js & MongoDB Backend

Important Notes

  • Always test payments using sandbox/test credentials before switching to live mode
  • Make sure your merchant account is fully activated with the payment provider
  • Some gateways may require webhook URLs, which are already handled by FoodBite

Need Help?

If a payment gateway is not working as expected:

  • Double-check the entered credentials
  • Confirm the selected mode (Test / Live)
  • Review the troubleshooting section for the specific gateway

For further assistance, contact FoodBite Support with the gateway name and error details.
