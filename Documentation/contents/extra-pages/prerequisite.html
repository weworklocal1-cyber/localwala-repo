Prerequisites

Before installing FoodBite – Multi-Restaurant Food Delivery Platform, please ensure that your system meets the following prerequisites. These requirements apply to the Backend Server, Admin Panel (Angular + Material), and Mobile Apps (Flutter + Bloc).

Server Prerequisites (Backend – Node.js)

Server & OS

  • Linux-based server (Ubuntu 20.04+ recommended)
  • VPS or Dedicated Server (AWS, DigitalOcean, Vultr, etc.)
  • Minimum 2 GB RAM (4 GB recommended)
  • Minimum 2 CPU cores
  • Public IP address
  • SSH access enabled

Node.js Environment

  • Node.js version 16.x or higher (Recommended)
  • Minimum supported: Node.js ≥ 12.x
  • NPM or Yarn
Important
Node.js backend usage:
  • Local Machine → Development & testing only
  • Production Server → Live application
Never use a local development server for production users.

Database

  • MongoDB version 5.0 or higher
  • MongoDB Atlas or Self-hosted MongoDB
  • Database user with read/write permissions
Important
MongoDB can be used locally for development and testing using MongoDB Compass.
  • MongoDB Atlas (Recommended) – backups, security, reliability
  • Self-hosted MongoDB – only if properly secured
Do NOT use a local MongoDB instance for live production traffic.

Process & Web Server

  • PM2 (production process management)
  • Nginx or Apache
  • SSL Certificate (HTTPS required)

Environment Configuration

Ability to configure environment variables for:

  • MongoDB connection
  • JWT authentication
  • Firebase credentials
  • Payment gateway keys
  • Email (SMTP) credentials
  • Cloud storage credentials (optional)

Managed using dotenv

Admin Panel Prerequisites (Angular + Material)

System Requirements

  • Node.js installed
  • NPM or Yarn
  • Stable internet connection

Angular Framework

  • Angular CLI (latest stable)
  • Angular-compatible Node.js version
  • TypeScript support

UI Framework

  • Angular Material
  • Angular CDK
  • Material Icons support

Browser Support

  • Google Chrome (recommended)
  • Mozilla Firefox
  • Microsoft Edge

Build & Deployment

  • Ability to build Angular app for production
  • Web server: Nginx or Apache
  • Domain or subdomain access
Important
The Angular Admin Panel must be built on your local machine, not on the production server.
Only the generated dist/ files should be uploaded.

Recommended Knowledge

  • Angular component & module structure
  • Angular Material theming
  • Environment configuration (environment.ts)
  • REST API integration

Mobile App Prerequisites (Flutter + Bloc)

Development Environment

  • Flutter SDK (latest stable)
  • Dart SDK
  • Android Studio or VS Code
  • Android Emulator or Physical Device
  • macOS required for iOS builds

State Management

  • Flutter Bloc
  • Understanding of Bloc events & states
Important
Flutter apps do NOT run on the server.
The server is used only for the Node.js API backend.

Android Build Requirements

  • Android SDK
  • Gradle
  • Google Play Developer Account

iOS Build Requirements

  • macOS system
  • Xcode (latest stable)
  • Apple Developer Account
  • Provisioning profiles & certificates

App Configuration

  • API base URL
  • Firebase configuration files
  • Google Maps API key
Important
Flutter apps must be built locally.
Only generated APK / AAB (Android) or IPA (iOS) files should be used for publishing.

Third-Party Service Requirements

  • Google Maps API
  • Firebase (Push Notifications)
  • Payment Gateway (Stripe, Razorpay, PayPal, etc.)
  • SMTP Email Service
  • SMS Gateway (optional)

Security & Access

  • HTTPS enabled (mandatory)
  • Secure API key management
  • Firewall & port access
  • Environment variable configuration

CodeCanyon Buyer Notes

  • Server, domain & hosting costs are not included
  • Third-party service costs are not included
  • One license = One domain
  • Source code access is required
  • Installation support depends on support period
